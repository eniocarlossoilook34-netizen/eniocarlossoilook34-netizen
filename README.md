- 🔌 **Emerging domains** — Electrical grids, supply chains, neural networks

## 🌊 Philosophy

> "For a finite-size system to persist in time, it must evolve in such a way that it provides easier access to the imposed currents that flow through it."
>
> — **Adrian Bejan, Constructal Law**

This principle guides my research: whether studying blood flow through capillaries, water flow through river deltas, or heat flow through materials, the same fundamental law emerges. My work explores how to computationally model and optimize these processes.
